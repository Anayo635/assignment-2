### **Overview of the Flashcard Quiz Android App Assignment**  

#### **Introduction**  
This assignment focuses on developing a native Android application designed to enhance studying through interactive flashcards. The primary objective is to create an engaging quiz app that tests users' knowledge of history, provides instant feedback, and tracks performance to reinforce learning. By utilizing Kotlin and Android Studio, students will gain hands-on experience in mobile app development, UI design, and version control with GitHub.

#### **Background**  
Flashcards have long been recognized as an effective study tool due to their simplicity and ability to reinforce memory retention. Widely used across various educational domains, flashcards allow learners to assess their understanding of key concepts. This project digitizes the flashcard experience, offering users a structured platform to answer history-based questions, receive immediate feedback, and analyze their performance.

#### **Objectives**  
The goal is to develop a fully functional, intuitive Android application that presents users with a series of history-related quiz questions. The app will feature a streamlined interface with three primary screens:  
- **Welcome Screen** – Introduces the app and provides a starting point for the quiz.  
- **Flashcard Question Screen** – Displays history questions one at a time, allowing users to respond with "True" or "False" answers. Instant feedback on correctness is provided.  
- **Score Screen** – Summarizes the user's performance after completing five questions, offering an option to review the flashcards or exit the application.

#### **Key Features and Requirements**  

##### **User Interface (UI):**  
- **Welcome Screen:**  
  - Provides a brief overview of the app’s purpose.  
  - Displays a welcoming message.  
  - Includes a "Start" button to begin the quiz.  

- **Flashcard Question Screen:**  
  - Presents one question at a time.  
  - Offers two answer buttons: "True" and "False."  
  - Includes a "Next" button to progress through questions.  
  - Displays feedback ("Correct!" or "Incorrect") immediately after each response.  

- **Score Screen:**  
  - Summarizes the total correct responses out of five.  
  - Offers personalized feedback based on performance.  
  - Includes a "Review" button to revisit flashcards with correct answers.  
  - Provides an "Exit" button to close the application.  

##### **Development Requirements:**  
- Utilize **Kotlin** as the primary programming language within **Android Studio**.  
- Implement **five** history questions for the quiz.  
- Integrate version control through **GitHub repositories** and automate builds/testing with **GitHub Actions**.  
- Ensure **comprehensive code comments** to enhance readability and maintainability.
